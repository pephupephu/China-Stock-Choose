# 筛规则详解

> 本文解释 `src/screener.py` 中每一条规则的逻辑、判定与失败提示。
> 修改阈值的"工作流"是：调整 `.env.example`/默认值、改 README、
> 同步更新下方说明并提交。

## 数据范围与真实性声明

- **只筛选沪深京 A 股**（沪深主板 60xxxx、688xxx 科创板；深证主板
  000xxx / 002xxx 中小板、300xxx 创业板；北交所 4/8 开头）。
  宇宙抓取阶段直接剔除 **ST / \*ST 简称** 与 **B 股代码**
  （深圳 200xxx、上海 9xxxxx），因此 **ST、B 股、港股永远不会进入
  任何筛选分支**，邮件正文里也看不到它们。
- 所有指标取自公开披露：分红来自巨潮资讯网（`cninfo.com.cn`）、
  财务报表取自新浪财经（`finance.sina.com.cn`）、主营构成取自
  同花顺（`10jqka.com.cn`）、行业分类与行业均值取自申万指数
  （新浪镜像）。当数据点缺失时，宁可放行也不臆造。
- 本项目**不引用**任何券商研报、雪球评论、媒体观点等主观来源；
  阈值与结论只基于上面四个数据源的公开披露数据。
- 涉及定期报告字段（如分红、扣非净利润、审计意见、在建工程）
  以公司年报 / 半年报披露为准；股东减持、关联交易等重大事项
  通过年报附注或公告检索补齐。
- 推送结果中所有"在建重大工程"来自同花顺"主营业务构成"标签
  与年报"在建工程"附注，便于人工逐一回看原文复核。

## 硬过滤

### 1. ST / *ST
- **在数据抓取阶段已剔除**（`src/main.py` 的 universe 过滤中按简称
  含 `ST` 直接排除），所以 `ScreeningResult` 里 `is_st=True` 的记录
  不会再出现。
- 数据来源：`name` 字段来自 `stock_info_a_code_name` 简称。

### 2. 非标审计意见
- 当前默认 `RULE_EXCLUDE_QUALIFIED=true`，**默认剔除**非标审计
  意见的年报；如确实需要保留，将 `.env` 改为 `false`。
- 失败提示：`[non-standard audit] 非标审计意见`

### 3. 近 3 年股息率均 ≥ 4%
- 计算方式：当年现金分红总额 / 期末收盘价 = `dividend_yield_pct_at_close`。
  仅看**年报现金分红**，剔除送股、转增。
- 必须**每一年**股息率 ≥ 4% 才通过；只要其中一年低于 4%，直接剔除。
- 时间窗口通过 `RULE_DIVIDEND_LOOKBACK_YEARS`（默认 `3`）调节。
- **不做"每股分红 > 0.5 元"等金额阈值过滤**，仅按"分红率（收益率）"筛，
  满足用户最新规则。
- 失败提示：`[近3年股息率≥4%] 近3年股息率任意一年 < 4%`

### 4. TTM 市盈率 ∈ (0, 30)
- PE 缺失或 ≤ 0 → 视作无效。
- PE ≥ 30 → 视作高估（高 PE 通常是行业冷门或预期透支）。
- 失败提示：`[TTM 市盈率 0<PE<30] TTM PE <= 0` 或 `> 30`。

### 5. 近 3 年扣非净利润 > 0
- 来源：新浪利润表中"扣除非经常性损益后的净利润"。
- 失败提示：`[近3年扣非净利润 > 0] 近3年扣非净利润非全正`

### 6. 近 3 年 ROE > 10%
- 计算：近 3 年扣非净利润 / ((期初权益 + 期末权益) / 2) 的年化结果。
- 失败提示：`[近3年 ROE > 10%] ROE TTM X.X% < 10%`

### 7. 资产负债率 ≤ 70%（警告阈值 60%）
- 负债率 ≤ 60%：绿灯；
- 60% < 负债率 ≤ 70%：仍通过硬过滤，但备注警示；
- 负债率 > 70%：直接剔除。
- 失败提示：`[负债率 < 70%] 负债率 X.X% > 70%`

### 8. 分红支付率 ≥ 40%
- 来源：当年现金分红总额 / 归母净利润。
- 100% 以上**仅警告，不剔除**（透支式分红，可持续性差）。

### 9. 经营性现金流对分红的支撑（默认仅警告）
- `RULE_REQUIRE_OCF_COVERS_DIVIDEND=false`（默认）时，OCF < 分红总额
  **仅作为警示列入备注**，并不剔除；如果想严格化，把开关改成 `true`。
- 失败提示（仅在 `true` 时）：`[OCF 覆盖分红] 经营性现金流 < 当年分红总额`

### 10. 每股经营现金流 > 0
- 失败提示：`[每股经营现金流 > 0] 每股OCF X.XX <= 0`

### 11. 主营收入 YoY 最大跌幅 ≤ 20%
- 取近 3 年主营收入 YoY（`metrics._annual_yoy_pct(..., window=3)`），
  任何一年跌幅超过 20% 即剔除。
- 数据缺失则**通过**（机器保守放行），并在 markdown 备注"主营收入数据缺失"。

### 12. 不做市值过滤
- 用户最新规则明确"不要市值"，本项目不对自由流通市值或总股本
  设定硬性区间；如需排查市值分布，可在 markdown 备注里看到现价
  但**不参与打分/淘汰**。

## 警告而非剔除

| 标签 | 触发 | 视觉位置 |
| --- | --- | --- |
| 透支式分红 | 分红支付率 > 100% | 表格备注列 |
| 分红现金流支撑不足 | OCF < 分红总额（默认不剔除，仅标注） | 表格备注列 |
| 负债率 > 60% | 负债率超线 | 表格备注列 |
| 主业收入下降超 20% | YoY 最大跌幅超限 | 表格备注列 |

## 观测字段（不做过滤，人工判断）

| 字段 | 来源 | 用途 |
| --- | --- | --- |
| 板块 / 行业（申万） | 申万指数（新浪镜像） | 行业归属 |
| 上市时间 | 公司公告（最早可披露期） | 上市年限 |
| 现价 / 报价时点 | 新浪日 K | 当下估值锚 |
| 市赚率（PC Ratio，股价/每股经营性现金流） | 新浪日 K + 现金流量表 | 与 PE 并列的估值参考 |
| 每股 OCF | 新浪现金流量表 | 与第 10 条联动 |
| 在建工程 / 重大事项 | 同花顺主营构成 + 年报附注 | 人工核实持续投入 |

## 评分

`score = 0.5 * avg_dividend_yield + 0.3 * ROE + 0.1 * (-debt_ratio / 100 * 50) + 0.1 * min(payout_ratio, 100)`

- `avg_dividend_yield` 为近 3 年股息率均值（百分点）。
- `ROE` 即 ROE(TTM)，百分点。
- `debt_ratio / 100 * 50` 限定负债率惩罚上限为 50%，避免极端值失控。
- `payout_ratio` 截断到 [0, 100]，避免"透支式分红"的反向加权。
- 一次性特别分红（`is_one_time_dividend`）扣 15 分，**不剔除**。

## 排序与节选

- 邮件正文与控制台只展示**前 50 条**命中清单（按 `score` 降序）。
- 全量数据落在 `output/pick_YYYY-MM-DD.json`，可作后续回测用。
- **被规则剔除的标的不会出现在邮件正文**（避免 ST / 旧经济周期
  类被剔标的干扰阅读；如需完整审计数据请打开 JSON 附件）。
