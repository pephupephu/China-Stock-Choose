# 筛规则详解

> 本文解释 `src/screener.py` 中每一条规则的逻辑、判定与失败提示。
> 修改阈值的"工作流"是：调整 `.env.example`/默认值、改 README、
> 同步更新下方说明并提交。

## 硬过滤

### 1. ST / *ST
- 触发条件：`name.upper()` 含 `ST` / `*ST` / `SST` / `S*ST`。
- 失败提示：`[ST/*ST] 属于 ST / *ST`
- 数据来源：`name` 字段来自 `stock_info_a_code_name` 简称。

### 2. 非标审计意见
- 当前默认 `RULE_EXCLUDE_QUALIFIED=False`，**不强制剔除**，但
  报告里仍标注 `audit_opinion` 供人工判断。
- 若要开启：编辑 `src/screener.py` 的 `exclude_qualified` 标志，或
  在 `ScreenerRules` 增加可调环境变量。

### 3. 近 2 年股息率 ≥ 4%
- 计算方式：取 cninfo 派现数据 → `cash_per_share = 派现比例 / 10`；
  `dividend_yield = cash_per_share / 期末收盘价`。
- 失败提示：`[近2年股息率≥4%] 近2年股息率均 < 4%`
- 备注：用户原始需求里要求"不要每股分红"，因此本项目**始终按"分红率"**
  而不是"每股分红"做筛选。

### 4. TTM PE ∈ (0, 30)
- PE 缺失或 ≤ 0 → 视作无效。
- PE ≥ 30 → 视作高估。
- 失败提示：`[TTM 市盈率 0<PE<30] TTM PE <= 0` 或 `> 30`。

### 5. 近 3 年扣非净利润 > 0
- 来源：Sina 利润表中"扣除非经常性损益后的净利润"。
- 失败提示：`[近3年扣非净利润 > 0] 近3年扣非净利润非全正`

### 6. ROE(TTM) ≥ 10%
- 计算：TTM 净利润 / ((期初权益 + 期末权益) / 2)。
- 失败提示：`[近3年 ROE > 10%] ROE TTM X.X% < 10%`

### 7. 资产负债率 ≤ 70%
- 期末值；如果上一年负债率高于此线但当年低于，仍然有效。
- 失败提示：`[负债率 < 70%] 负债率 X.X% > 70%`

### 8. 分红支付率 ≥ 40%
- 来源：`现金分红总额 / 归母净利润`。
- 100% 以上**仅警告，不剔除**（透支式分红）。

### 9. 经营性现金流 ≥ 当年分红总额
- 取年报"经营活动产生的现金流量净额"vs`分红总额`。
- 失败提示：`[OCF 覆盖分红] 经营性现金流 < 当年分红总额`

### 10. 每股 OCF > 0
- 失败提示：`[每股经营现金流 > 0] 每股OCF X.XX <= 0`

### 11. 主营收入 YoY 最大跌幅 ≤ 20%
- 当 `main_revenue_yoy_pct_list` 中最小的 YoY 跌幅超过 20% 时，剔除。
- 数据缺失则**通过**（机器保守放行），并在 markdown 备注。

## 警告而非剔除

| 标签 | 触发 | 视觉位置 |
| --- | --- | --- |
| 透支式分红 | 分红支付率 > 100% | 表格备注列 |
| 分红现金流支撑不足 | OCF < 分红总额 | 表格备注列（同时也是硬过滤之一） |
| 负债率 > 60% | 负债率超线 | 表格备注列 |
| 主业收入下降超 20% | YoY 最大跌幅超限 | 表格备注列 |

## 评分

`score = 0.5 * avg_dividend_yield + 0.3 * ROE - 0.5 * debt_ratio + 0.1 * payout`

- 一次性特别分红（`is_one_time_dividend`）扣 15 分，**不剔除**。

## 排序与节选

- 邮件正文只展示前 50 条被剔除记录，避免邮件体积过大。
- 全量数据落在 `output/pick_YYYY-MM-DD.json`，可作后续回测用。
